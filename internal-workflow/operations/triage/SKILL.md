# Triage Operation

Inspect the supplied issue and repository evidence without edits or external
writes. Use packaged [Plan](../../skills/plan/SKILL.md) and [coding
routing](../../docs/agents/coding-skill-routing.md) for the distinction between
a direct deterministic implementation and a real product or ownership gap.
Use [Bug Root Cause Explainer](../../skills/bug-root-cause-explainer/SKILL.md)
for diagnosis-only evidence. External research is outside this network-denied
operation and remains a separate packaged side primitive.

Return exactly one package route in `schemas/triage-route-v1.json`: direct,
spec-required, or a typed blocker. Product decision gaps belong to Plan and the
Runner's spec-author adapter; technical implementation choices never stop
triage.
